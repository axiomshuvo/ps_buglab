Console

A user list that never renders

Click Load users. The list below should fill in — it won't, and it'll sit on "Loading…" forever.

No users loaded yet.
Where to look
  1. Open the Console tab.
  2. You'll see Uncaught (in promise) TypeError: Cannot read properties of undefined (reading 'map').
  3. Click the file:line link on the right of the error to jump straight to that line in Sources.
  4. The response actually looks like { data: { users: [...] } } — the code reads response.users instead of response.data.users.
Network

A login that quietly fails

Click Log in. Nothing dramatic happens on screen — the interesting part is what the request actually looked like.

Not signed in.
Where to look
  1. Open the Network tab, then click Log in.
  2. Find the request (filter by Fetch/XHR) and click it.
  3. Headers tab: status is 401. Payload: your fake credentials were sent exactly as typed.
  4. Since the request itself went out fine, this isn't a frontend bug — it points straight at credentials or the backend.
Elements

A button with nothing attached

Click Save changes. Watch closely — it does genuinely nothing, not even an error you can see on screen.

Not saved
Where to look
  1. Open Elements, select the "Save changes" button, then open the Event Listeners tab in the right-hand panel.
  2. No click entry is listed — the handler never attached in the first place.
  3. Check Console — you'll find Cannot read properties of undefined (reading 'theme'), thrown before the addEventListener line ever ran.
Application

A plan upgrade that doesn't show up

localStorage is standing in for a cache here — same bug pattern as a stale service-worker cache, just easier to inspect in a single file.

Plan: —

Where to look
  1. Click "Upgrade to Pro", then "Refresh status" — it still says Free plan.
  2. Open Application → Local Storage for this page and find demo_plan_cache.
  3. It's stuck on the old value — nothing invalidates it when the "server" changes.
  4. Delete that key, or click "Clear cached data", then refresh again.
Sources

A total that comes out as $NaN

Pick a region and calculate the total. Most regions work fine. One doesn't.

Subtotal: $120.00 · Total: $—
Where to look
  1. Pick "Canada" and click Calculate — total shows $NaN.
  2. Open Sources, find this file, and set a breakpoint on the const total = subtotal + subtotal * taxRate; line inside calculateTotal.
  3. Click Calculate again — execution pauses. Check the Scope panel: taxRate is undefined.
  4. Step out one level — getTaxRate('CA') returned undefined because 'CA' isn't in the TAX_RATES map.
